

# 🏎 F1CalendarBot

Un bot de Telegram simple que te notificará 10 minutos antes de que comience una nueva sesión de F1.

Puedes ir a Telegram y buscar: [@f1CalendarAlert_bot](https://t.me/f1CalendarAlert_bot)

## ⌨️ Comandos

`/subscribe` Úsalo para recibir notificaciones

`/unsubscribe` Úsalo para dejar de recibir notificaciones

`/nextrace` Úsalo para obtener información sobre el próximo GP
